* [inithooks] a hook script's timeout on Windows now kills its whole process tree, not just the shell: TerminateProcess previously reached only the shell, so a backgrounded descendant (e.g. `sleep 5 &`) was orphaned and kept running, still holding whatever handle it had inherited from the shell — including, under `go test`, the test binary's own stdout pipe, which reds the pre-push gate after every test has passed. Unix already killed the whole process group on timeout; Windows now does too, via a Job Object with JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE (#947)
