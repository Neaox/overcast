* [ec2] a filter value is matched as the pattern AWS treats it as, so `*` stands for any run of characters, `?` for exactly one, and a backslash asks for a literal one. Overcast compared values exactly, which quietly narrowed every wildcard filter to nothing: `--filters 'Name=tag:Name,Values=overcast-*'` selected no VPC, and CDK's `MachineImage.lookup` — whose `name` filter is a wildcard in every documented example — found no AMI and failed the synth with `AmiNotFound`. Tag selectors get the same treatment, since `tag:Name` is where a wildcard is most often reached for
