[router/cognito] the emulated data plane joins the reserved prefix, and it is the last group to do so: `/_appsync/{apiId}/…` is now `/_overcast/appsync/apis/{apiId}/…`, `/_cloudfront/{distId}/…` is `/_overcast/cloudfront/distributions/{distId}/…`, `/_apigateway/execute-api/…` is `/_overcast/apigateway/execute-api/…`, `/_lambda/url-invoke/…` is `/_overcast/lambda/url-invoke/…`, `/_elb` is `/_overcast/elb`, API Gateway's WebSocket management API moves from `/@connections/{apiId}/{stageName}` to `/_overcast/apigateway/connections/{apiId}/{stageName}`, and Cognito's managed login moves from `/_cognito/{poolId}/…` to `/_overcast/cognito/user-pools/{poolId}/…`. Sixteen internal path roots are now one
  migration: nothing changes for host-addressed callers — an execute-api, AppSync or Lambda function URL resolves to these paths internally and the URL you were given is unaffected, as are application redirect URIs. Two things need attention: a hard-coded Cognito hosted-UI URL (the OIDC discovery document regenerates itself, so a client that reads `authorization_endpoint` needs no change), and a caller posting to `/@connections/…` by path rather than through the API Gateway Management API endpoint. JWT issuers and token validation are unaffected
