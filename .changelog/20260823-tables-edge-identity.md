~ [web] the API Gateway, AppSync, WAF and Cognito tables now sort. API Gateway's API list (both the REST and HTTP tabs), the WAF Web ACL list and the Cognito user pool list are `ResourceTable`s now, so their identity, id and timestamp columns sort on a header click and a columns menu hides the ones you are not reading; WAF and Cognito additionally deep-link the sort as `?sort=name` / `?sort=-created`, alongside the filter's `q` that Cognito already carried. Fourteen sub-tables on the detail pages moved with them — API Gateway's routes, integrations, stages, deployments and authorizers, AppSync's data sources, resolvers, functions, API keys and schema types, and Cognito's users and group members — which is what gives each of them a real loading skeleton, a load-error state and a delete confirmation identical to every other list in the UI, where several previously showed a bare "None defined." line whether the call was in flight, empty or failed. The REST API's resource tree and the Cognito user's attribute grid stay hand-rolled: the first expands a row into per-method rows, the second is an editable name/value grid rather than a resource list (#1327).
