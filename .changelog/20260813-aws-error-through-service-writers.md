* [debug] a DynamoDB or CloudFront error reaches its trace, the request log and retention like every other service's. Both wrap the ResponseWriter again for their own reasons — DynamoDB for the `X-Amz-Crc32` header, CloudFront for access logging — and `protocol.recordAWSError` type-asserts whichever writer the handler holds, so a wrapper that answers the assertion without forwarding ends the chain without failing. Every wrapper in the serving path now forwards, and a source-level ledger fails the build when a new one does not
