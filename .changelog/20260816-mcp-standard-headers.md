*. [mcp] a request that mirrors its method and target into HTTP headers now has them checked against the body. MCP revision `2026-07-28` requires a modern client to repeat its method in `Mcp-Method`, and the thing it names in `Mcp-Name` on `tools/call`, `resources/read` and `prompts/get`, so that load balancers and gateways can route and inspect a request without parsing it. The value of that mirroring depends on the two agreeing: a header saying one thing while the body says another means an intermediary and the server are handling different requests, which is exactly the confusion the rule exists to prevent, so a disagreement is refused with `-32020` and `400 Bad Request`. A name that cannot be sent as plain ASCII is decoded from its base64 form before comparison, so a correct request is not read as a mismatch. Two exemptions are deliberate and unchanged behaviour: a `2025-11-25` request is never held to a rule its revision does not define, and the stdio transport is exempt because header mirroring is a property of the HTTP binding rather than of the protocol — stdio has no envelope to mirror into and no intermediaries to serve
