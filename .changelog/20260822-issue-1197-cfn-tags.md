* [cloudformation/cloudtrail] AWS::CloudTrail::Trail stopped dropping Tags (#1197); tags now thread through Create (as CloudTrail's own TagsList member) and reconcile via AddTags/RemoveTags on update, since Tags has no UpdateTrail member.
* [cloudformation/transfer] AWS::Transfer::Server and AWS::Transfer::User stopped dropping Tags on update, and User stopped dropping them on create too (#1197). A tags-only Server update now reconciles via TagResource/UntagResource instead of forcing a replacement; any other property change still forces one, unchanged from before.
* [cloudformation/iam] AWS::IAM::ManagedPolicy and AWS::IAM::InstanceProfile stopped dropping Tags (#1197); both thread Tags inline at create and reconcile add/change/remove on update, the same TagPolicy/UntagPolicy and TagInstanceProfile/UntagInstanceProfile follow-up AWS::IAM::Role and AWS::IAM::User already used.
