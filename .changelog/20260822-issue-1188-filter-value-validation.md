* [secretsmanager] `ListSecrets` and `BatchGetSecretValue` now reject a `Filters` entry whose `Key` is outside AWS's enum with `InvalidParameterException`, matching one of each operation's own declared errors, instead of silently matching no secrets.
*. [stepfunctions] `ListExecutions` now rejects a `statusFilter` value outside the `ExecutionStatus` enum with `ValidationException`, one of the operation's own declared errors, instead of silently matching no executions.
*. [cloudformation] `ListStacks` now rejects a `StackStatusFilter` value outside AWS's full `StackStatus` enum with `ValidationError`, instead of silently matching no stacks. The complete 23-value enum is now modelled — including the IMPORT_* states Overcast itself never produces — so a caller legitimately filtering on one of those is still accepted.
