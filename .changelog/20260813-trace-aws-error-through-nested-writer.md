* [debug] a trace records the AWS error code and message its request answered with, so the trace list can be searched by them and a 2xx carrying an AWS error is recognised as a failure worth keeping. `protocol.recordAWSError` type-asserts the `ResponseWriter`, and `RequestEvents` builds a second `responseWriter` around `Logger`'s — so the handler recorded onto the inner instance while `Logger` read the outer one. The assertion succeeded every time and the value simply landed where nothing read it; the recording now forwards through the chain. The request log gains its `aws_error_code` field back with it
