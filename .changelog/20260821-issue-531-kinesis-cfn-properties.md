* [cloudformation/kinesis] AWS::Kinesis::Stream stopped dropping RetentionPeriodHours, Tags, StreamEncryption and StreamModeDetails (#531) RetentionPeriodHours now threads through Increase/DecreaseStreamRetentionPeriod on create and reconciles on update; a CDK stream with `retentionPeriod: Duration.days(7)` no longer reports Kinesis' 24-hour default. Tags reconcile via AddTagsToStream/RemoveTagsFromStream. StreamModeDetails and StreamEncryption are new Kinesis fields, threaded at create and reconciled via the new UpdateStreamMode/StartStreamEncryption/StopStreamEncryption operations, and round-trip through DescribeStream/DescribeStreamSummary. ShardCount changes still force replacement (UpdateShardCount is not implemented, #1096); an unnamed stream now gets a generated per-instance name so that replacement does not collide with the still-live original.
