* [cloudformation] EC2's `DependencyViolation` now routes through the same deletion-blocked sentinel as IAM's `DeleteConflict`, RDS's deletion protection, and a non-empty S3 bucket. `DeleteInternetGateway`, the main-table case of `DeleteRouteTable`, and `DeleteVpnGateway` all refuse while something is still attached — that refusal is now marked as the lasting condition it is rather than reported the same as an ordinary, possibly transient, delete failure.
