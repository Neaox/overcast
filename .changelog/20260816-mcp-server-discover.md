*. [mcp] the server answers `server/discover`, so a client can ask what it speaks before committing to how it talks. MCP revision `2026-07-28` requires the method and uses it as the era probe: a client that does not yet know whether a server negotiates with `initialize` or serves each request statelessly sends this first and reads the answer. It reports the protocol versions the server supports — one, `2026-07-28` — along with its capabilities and identity, and is answerable with no handshake and no declared version, since a client asking which versions exist cannot be expected to have picked one. A client that does declare a version still has it validated, and an unsupported one is refused with the same supported list this method would have returned
